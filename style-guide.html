07

Layout grid

Every one of the five screens follows the same four-zone skeleton.
1 · Header / tabs sticky 44–56 px
2 · Search + filter chips sticky 52 + 56
3 · Scroll body  (flex: 1)
4 · Bottom navigation 72 px + safe area
  • • One column, single scroll region — 16 px gutters, 20 px card padding.
  • • Zones 1 & 2 stay sticky; only zone 3 scrolls.
  • • Chip rails scroll edge-to-edge and clip the last chip as a “there is more” cue.
  • • Header FAB sits top-right in zone 1, above the search field.
  • • Touch targets ≥ 44 × 44 px; agent row min-height 72 px.

⚠️ fails small text
Never render white text smaller than 14 px / 600 on #00C951. For small green labels, use --green-700 on white instead.
Never encode state with colour alone — pair the green dot with a word (“NEW”, “Agent generated”) and the active tab with an underline as well as colour.
09

Do & Don’t

The rules that keep the look intact.

✅ Do

  • ✓ Keep ~88% of the screen white / near-white
  • ✓ Use green only for action + active state
  • ✓ Fill with --green-500, write with --green-700
  • ✓ 24 px radius cards, pill chips
  • ✓ Grey descriptions, light meta — hierarchy via colour
  • ✓ Serif headline + mono controls inside documents
  • ✓ Pastel discs behind mascot avatars
  • ✓ Shadows ≤ 6% opacity

❌ Don’t

  • ✕ Fill backgrounds with colour blocks
  • ✕ Use green for decoration or borders
  • ✕ Put white small text on --green-500
  • ✕ Square corners / 4 px radii
  • ✕ Bold descriptions for hierarchy
  • ✕ Use serif anywhere in the app chrome
  • ✕ Recolour the mascots themselves
  • ✕ Heavy drop shadows or dark borders
